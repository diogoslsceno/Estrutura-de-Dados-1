# Estrutura de Dados I

Repositório com os códigos desenvolvidos durante a disciplina de **Estrutura de Dados I**.

Ao longo do semestre, este repositório será atualizado com exemplos, exercícios e implementações realizadas em sala de aula.

## Conteúdo

Os códigos serão organizados por aula e abordarão tópicos como:

- Vetores
- Matrizes
- Ponteiros
- Structs
- Alocação dinâmica
- Listas
- Pilhas
- Filas
- Outros conteúdos da disciplina

## Organização

Cada pasta representa uma aula ou atividade desenvolvida durante o curso, facilitando a consulta e o acompanhamento da evolução dos estudos.

## Linguagem

- C

## Objetivo

Centralizar todo o material produzido durante a disciplina, servindo como registro do aprendizado e material de apoio para revisões futuras.
